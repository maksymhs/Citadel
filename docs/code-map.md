## Tests

One suite per area in `tests/<area>.test.js` (`node:test`, each with its own throwaway database under `data/`). Match the name of the route, service or script you changed: `monitor.test.js` for `monitorService.js`, `pairing.test.js` for `pairingService.js`, and so on.
